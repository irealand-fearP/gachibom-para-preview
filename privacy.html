개인정보 처리방침

가치봄 제주는 로그인 없이 이용하는 접근성 여행 정보 서비스입니다. 현재 공개 버전은 이름, 연락처, 계정 또는 건강정보를 서버에 저장하지 않습니다.

1. 처리하는 정보

여행 조건과 저장 코스
사용자 기기의 브라우저 저장소에만 보관되며 운영자 서버로 전송되지 않습니다.
현재 위치
사용자가 가까운 시설 검색을 요청하고 권한을 허용한 경우에만 일시적으로 사용합니다. 위치를 별도로 저장하지 않습니다.
접근 기록
호스팅·지도·이미지 제공 과정에서 IP 주소, 브라우저 종류 같은 일반적인 접속 정보가 각 서비스 제공자에게 전달될 수 있습니다.

2. 이용 목적과 보관 기간

여행 조건은 추천 결과를 만들기 위해, 현재 위치는 가까운 접근성 시설을 찾기 위해 사용합니다. 브라우저 저장소의 코스는 사용자가 삭제하거나 브라우저 데이터를 지울 때까지 해당 기기에 남습니다.

3. 외부 서비스

지도와 경로 표시를 위해 OpenStreetMap, CARTO 및 OSRM 등의 공개 서비스를 이용할 수 있습니다. 장소 근거 링크를 누르면 Visit Jeju, 공공데이터포털, 카카오맵 등 외부 사이트로 이동할 수 있으며 해당 서비스의 정책이 적용됩니다.

4. 이용자의 선택

현재 위치 권한을 거부해도 장소 추천과 방문정보를 이용할 수 있습니다. 저장한 코스는 앱의 저장함에서 삭제할 수 있고, 브라우저 설정에서 사이트 데이터를 지울 수도 있습니다.

5. 문의와 변경

개인정보 또는 접근성 정보 관련 문의는 가치봄 제주 GitHub 문의 페이지에서 접수할 수 있습니다. 서비스 기능이 달라지면 이 방침의 시행일과 내용을 함께 갱신합니다.
