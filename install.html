휴대폰에 앱처럼 설치하세요

별도 회원가입이나 앱스토어 없이 바로 사용할 수 있습니다. 설치 후 홈 화면의 가치봄 제주 아이콘을 누르면 전체 화면으로 실행됩니다.

설치 없이 앱 실행

Android Chrome에서는 설치 버튼이 자동으로 표시됩니다. iPhone은 아래 안내를 따라 주세요.

팀원에게 공유

QR을 찍으면 설치 화면이 열려요

휴대폰 카메라로 QR을 찍거나 아래 주소를 누르세요. 가치봄 제주 설치 화면으로 바로 연결됩니다.

설치 화면 바로 열기

카메라가 바로 인식하지 못하면 위 링크를 누르세요.

Android · Chrome

  1. Chrome에서 가치봄 제주를 엽니다.
  2. 상단의 앱 설치 버튼이나 브라우저 메뉴의 홈 화면에 추가를 누릅니다.
  3. 설치를 누르면 홈 화면에 아이콘이 만들어집니다.

iPhone · Safari

  1. Safari에서 가치봄 제주를 엽니다.
  2. 하단의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택한 뒤 추가를 누릅니다.

iPhone에서는 Safari를 사용해야 홈 화면 설치 메뉴가 정확히 표시됩니다.
